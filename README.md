# 나만의 퀴즈 게임

터미널에서 동작하는 4지선다 수학 암산 퀴즈 게임입니다.

## 프로젝트 개요

Python 기본 문법과 클래스, JSON 파일 입출력만으로 구현한 콘솔 프로그램입니다.
외부 라이브러리 없이 표준 라이브러리(`json`)만 사용했습니다.

메뉴에서 번호를 선택해 퀴즈를 풀거나, 새 문제를 등록하거나, 등록된 목록과
최고 점수를 확인할 수 있습니다. 추가한 퀴즈와 최고 점수는 `state.json`에
저장되므로 프로그램을 종료하고 다시 실행해도 그대로 유지됩니다.

## 퀴즈 주제와 선정 이유

**주제: 수학 암산**

- **정답이 하나로 명확합니다.** 상식이나 취향이 개입할 여지가 없어서, 채점 로직이
  맞는지 틀린지를 헷갈릴 일이 없습니다. 덕분에 문제 자체보다 프로그램이 제대로
  동작하는지에 집중할 수 있었습니다.
- **문제를 무한히 만들 수 있습니다.** 퀴즈 추가 기능을 테스트할 때 소재를 고민할
  필요가 없어, 입력 검증과 파일 저장이 잘 되는지 반복해서 확인하기 좋았습니다.
- **연산 순서를 묻는 문제처럼 난이도를 조절하기 쉽습니다.** `12 + 3 × 4` 같은
  문제를 섞으면 단순 계산과 규칙 이해를 함께 다룰 수 있습니다.

## 실행 방법

**요구 환경**: Python 3.10 이상 (외부 라이브러리 불필요)

```bash
git clone https://github.com/heeseo0616/quiz-game.git
cd quiz-game
python3 main.py
```

이미 저장소가 있다면 폴더로 이동해서 바로 실행하면 됩니다.

```bash
cd quiz-game
python3 main.py
```

## 기능 목록

| 메뉴 | 기능 | 설명 |
|:---:|---|---|
| 1 | 퀴즈 풀기 | 등록된 모든 퀴즈를 순서대로 출제하고 채점합니다. 결과를 최고 기록과 비교해 갱신합니다. |
| 2 | 퀴즈 추가 | 문제, 선택지 4개, 정답 번호를 입력받아 등록하고 즉시 파일에 저장합니다. |
| 3 | 퀴즈 목록 | 등록된 퀴즈의 개수와 문제 목록을 보여줍니다. |
| 4 | 점수 확인 | 최고 점수를 `점수(맞힌 수/총 문제 수)` 형태로 보여줍니다. |
| 5 | 종료 | 현재 상태를 저장하고 프로그램을 종료합니다. |

### 입력 및 예외 처리

숫자를 입력받는 모든 지점은 `ask_number()` 함수 하나가 담당하며, 아래를 모두
처리하고 조건을 만족할 때까지 다시 입력받습니다.

- 앞뒤 공백 제거 (`" 1 "` → 정상 처리)
- 빈 입력 (그냥 Enter)
- 숫자로 변환할 수 없는 입력 (`abc`)
- 허용 범위 밖의 숫자 (메뉴에서 `9`, 정답에서 `0`)

이 밖에 아래 상황도 처리합니다.

- `Ctrl+C`(KeyboardInterrupt) 또는 입력 종료(EOFError) 시 안내 후 저장하고 정상 종료
- 데이터 파일이 없으면 기본 퀴즈 5개로 시작
- 데이터 파일이 손상되었으면 안내 후 기본 퀴즈로 초기화

## 파일 구조

```
quiz-game/
├── main.py       # 프로그램 전체 (함수 3개 + 클래스 2개)
├── state.json    # 퀴즈와 최고 점수 저장 파일 (실행 시 자동 생성)
├── README.md
└── .gitignore
```

`main.py`의 구성은 다음과 같습니다.

| 구분 | 이름 | 역할 |
|---|---|---|
| 함수 | `ask_number` | 범위 안의 정수를 받을 때까지 반복 입력 |
| 함수 | `ask_text` | 비어 있지 않은 문자열을 받을 때까지 반복 입력 |
| 함수 | `score_percent` | 맞힌 개수와 총 문제 수로 100점 만점 점수 계산 |
| 클래스 | `Quiz` | 퀴즈 한 문제 (문제, 선택지, 정답) |
| 클래스 | `QuizGame` | 게임 전체 관리 (퀴즈 목록, 최고 점수, 파일 입출력) |

## 데이터 파일 설명 (`state.json`)

- **경로**: 프로젝트 루트의 `state.json`
- **인코딩**: UTF-8 (`ensure_ascii=False`로 저장해 한글이 그대로 기록됩니다)
- **역할**: 등록된 퀴즈 전체와 최고 점수 기록을 보관합니다. 프로그램을 종료해도
  데이터가 유지되도록 하는 파일입니다.
- **생성 시점**: 첫 실행 후 퀴즈를 추가하거나 프로그램을 정상 종료할 때 자동 생성됩니다.
  저장소에 파일이 없어도 프로그램은 기본 퀴즈 5개로 정상 동작합니다.

### 필드 구조

| 필드 | 타입 | 설명 |
|---|---|---|
| `quizzes` | list | 퀴즈 객체들의 목록 |
| `quizzes[].question` | str | 문제 텍스트 |
| `quizzes[].choices` | list[str] | 선택지 4개 |
| `quizzes[].answer` | int | 정답 번호 (1~4) |
| `best_score` | int | 최고 기록에서 맞힌 문제 수 |
| `best_total` | int | 그때 푼 총 문제 수 (0이면 아직 플레이 기록 없음) |

### 예시

```json
{
  "quizzes": [
    {
      "question": "15 + 27 = ?",
      "choices": ["32", "42", "52", "45"],
      "answer": 2
    },
    {
      "question": "12 + 3 × 4 = ?",
      "choices": ["60", "24", "19", "48"],
      "answer": 2
    }
  ],
  "best_score": 4,
  "best_total": 5
}
```

> `best_score`와 `best_total`을 함께 저장하는 이유는 두 가지입니다.
> 첫째, `5문제 중 4문제 정답 (80점)`처럼 총 문제 수까지 표시하기 위해서입니다.
> 둘째, `best_total`이 `0`인지로 **"아직 한 번도 풀지 않음"**과 **"0점을 받음"**을
> 구분할 수 있기 때문입니다.
